What is PromiseKit?

PromiseKit is a Swift promises library.

PromiseKit helps compose asynchronous work using promises. Developers searching for PromiseKit are often looking for the Swift API reference, the GitHub repository, Promise and Resolver behavior, or migration notes between older generated references.

The historical reference paths are preserved as archive pages because Search Console still shows impressions for older PromiseKit URLs. This overview keeps the current canonical PromiseKit entry point separate from individual class pages and old release-note URLs.

Who created PromiseKit?

PromiseKit was created and authored by Max Howell, also known as mxcl. The source repository is available on GitHub.

What are Promise, Resolver, and Guarantee?

Promise represents an asynchronous result, Resolver completes that result, and Guarantee represents asynchronous work that does not reject.
